# ⚡ Night City Match Tracker

**Track the game. Stay focused. Welcome to Night City.**

A lightweight, mobile-friendly Progressive Web App (PWA) designed to simplify match phase tracking in Cyberpunk TCG.

Built by a player, for the community.

### [⚡ Launch Night City Match Tracker](https://maccik.github.io/night-city-tracker/)

## Overview

Keeping track of consecutive turns with empty Fixer areas, Overtime, and additional turns after the round timer expires can lead to confusion between players.

Night City Match Tracker provides a shared visual reference, allowing both players to focus on the game rather than remembering which phase they are in.

## Features

- **Game Status Tracker**
  - Normal Play
  - No Gigs — Turn 1
  - No Gigs — Turn 2
  - Overtime

- **Round End Tracker**
  - Round in Progress
  - Finish Current Turn (Turn 0)
  - Additional Turn 1
  - Additional Turn 2
  - Additional Turn 3

- Independent phase tracking.
- Cyberpunk-inspired user interface.
- Responsive, mobile-first design.
- Offline support through a service worker.
- Installable as a standalone mobile application.
- Automatic match state persistence.
- Match reset with confirmation.
- No accounts, advertisements, or backend required.

## Getting Started

Open the application in your preferred browser.

You can also install it on your mobile device for a more native experience.

### Android

1. Open the application in Chrome.
2. Open the browser menu.
3. Select **Install app** or **Add to Home screen**.

### iOS

1. Open the application in Safari.
2. Tap the **Share** button.
3. Select **Add to Home Screen**.

Once installed and cached, the application can be used without an internet connection.

## How to Use

1. Start a new match with both trackers in their default states.
2. Update the Game Status tracker as the game progresses.
3. When the round timer expires, activate the Round End tracker.
4. Advance each tracker independently as required.
5. Reset the trackers before starting a new game.

The application is a manual tracking tool. It does not automatically validate game states or enforce game rules.

## Tournament Compatibility

The Round End tracker is designed to accommodate the three additional turns introduced in the November 2026 tournament rules update.

Always refer to the official rules for the latest procedures:

- [Official Tournament Rules](https://cyberpunktcg.com/tournament-rules)
- [Official Cyberpunk TCG Website](https://cyberpunktcg.com/)

**Important:** This application is not an official tournament accessory. Electronic device usage may be restricted during competitive play. Always obtain approval from the tournament organizer or Head Judge before using it during an official match.
